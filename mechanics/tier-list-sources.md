# Tier list sources

> **Covers:** which AFK Journey tier lists may be cited, which are banned, what each one ranks *for*, and the three things a tier letter must carry before it enters a file.
> **Updated:** 2026-08-31

A tier list is not one thing. A list built for AFK Stages and a list built for Arena rank the same hero differently, because the fights are different: AFK Stages rewards crowd control over minutes, Arena is settled in the opening seconds. A letter copied across that boundary is not weak evidence, it is wrong evidence.

Two failures put a bad letter in a file, and both are silent.

- **Age.** The game patches, heroes release, and the list stays where it was.
- **Purpose.** The list ranks for a mode this account is not asking about, and the file never records which one.

This file closes both. It names the sources that survive the check, so a session does not have to re-run the search, and so a letter already in the repo can be traced back or thrown out.

## The three-part rule

**A tier letter may only be written into a file when it carries all three of these. A letter missing any one of them is an opinion with no address, and it does not go in.**

1. **The mode it ranks for**, in the source's own words. Not "overall", not "general play". If the source gives one blended list and never says what the list is for, the letter fails this test.
2. **The source URL with a bracketed date**, per the `game-research` skill. Prefer a source inside **6 months**. Reject anything over **12 months**.
3. **The investment level assumed**, or a plain statement that the source does not state one. A list rating heroes at Mythic+ with Exclusive Equipment describes a hero this account may be five ascensions away from. See [progression-systems.md](progression-systems.md) and [hero-scoring.md](hero-scoring.md).

A letter that passes all three is still only evidence about the heroes that source covers. A hero the source never names is outside its scope, not below its bar. See the guide-silence rule in [hero-scoring.md](hero-scoring.md).

## The dating key

Fan sites stamp dead pages with today's date. Judge a list by the roster it names, not by the date it displays.

| Test | What it proves |
| --- | --- |
| Names **Rolan** or **Voracia** | The list is at or after version 1.7.3, 2026-08-06. |
| Names **Taichi & Agumon** or **Yamato & Gabumon** | The list is at or after the Digimon crossover, 2026-08-18. |
| Top tier is Korin, Marilee, Kruger, Odie, Reinier, Temesia or Scarlita, and Frieren, Galahad and Rolan appear nowhere | The list is 2024 content, whatever date it displays. |

Live version is **1.7.3**, released 2026-08-06. Live season is **Season 7, Crown of Ashes**, started 2026-05-29. See [seasons.md](seasons.md).

## Two traps that survive the date check

**Three sites agreeing can be one site agreeing with itself.** Puzzle carries the Yaphalla clan tag, and Yaphalla appears to feed Prydwen's tier list. Treat **Prydwen, Puzzle and Yaphalla as one opinion**. The independent current voices are allclash, afk.global, Pocket Tactics, GamsGo and that cluster. Five, not eight. So a number confirmed by Prydwen and Puzzle is confirmed once, and still needs a second source under the cross-check rule in the `game-research` skill.

**Top-up resellers inflate the newest hero, because they sell the currency used to pull her.** Voracia is the proof. Every independent source rates her B to D. Both resellers rate her S.

| Source | Type | Voracia |
| --- | --- | --- |
| allclash | independent | B PvE, B Dream Realm, B PvP |
| GamsGo | independent | B AFK Stages, C both Dream Realm boards, B PvP |
| afk.global | community vote | B overall |
| Pocket Tactics | independent | C story, D Dream Realm, D PvP |
| [LDShop](https://www.ldshop.gg/blog/afk-Journey/latest-heros-tier-list.html) | reseller | S |
| [TopUpLive](https://www.topuplive.com/news/afk-journey-hero-tier-list-2026.html) | reseller | S |

Apply the same discount to LDShop and TopUpLive on Rolan and on the Digimon pairs.

## Modes no current source covers

The pattern is clean. **The three modes with public leaderboards get covered. The rotating and limited modes get nothing.** For everything in the bottom half of this table there is no letter to borrow, and [hero-scoring.md](hero-scoring.md) does the whole job.

| Mode | Cover |
| --- | --- |
| Campaign and AFK Stages | Good. allclash, afk.global, Pocket Tactics, GamsGo. |
| Dream Realm, blended | Good. The same four. |
| Arena and PvP | Good. The same four, plus Puzzle. |
| Dream Realm Endless | Thin. Only afk.global, GamsGo and Prydwen separate it, and two of those cannot be fetched. Endless rewards HP-loss and true damage, so a blended Dream Realm letter is a real error here. See [game-modes.md](game-modes.md). |
| Dream Realm, per boss | Weak. LootBar only, and its hero picks look stale. |
| Supreme Arena | **None.** No dedicated ranking exists. Team comps only. |
| Honor Duel | **None since 2024-04-04.** The worst gap: version 1.7.3 rebalanced Gwyneth, Cyran, Nerion, Bonnie, Silvina and Valen *specifically for Honor Duel*, and no list reflects it. The mode also hands out its own heroes, so a roster tier list is the wrong tool. See [honor-duel.md](honor-duel.md). |
| Legend Trial | **None since 2024-04-30.** No current source respects the faction lock. See [legend-trial.md](legend-trial.md). |
| Arcane Labyrinth | **None.** Every search falls back to general lists. See [arcane-labyrinth.md](arcane-labyrinth.md). |
| Battle Drills | **None** except a 2024 page. See [battle-drills.md](battle-drills.md). |
| Dream Hunt and Clash of Glory | **None.** Both modes arrived in 1.7.3 and are weeks old. |

## The one place real numbers live

Public Dream Realm damage rankings and hero usage rates do not exist on the open web. The live data sits in the **Yaphalla Discord**, https://discord.gg/yaphalla, in a members-only Global Leaderboards channel, alongside a public tool site at https://yaphalla.com carrying a formation editor and an ascension planner. Joining is the only route to real damage numbers rather than opinion.

Reddit is not evidence either way. r/AFKJourney blocks crawlers, every mirror and archive route fails, and the only posts reachable through search indexes are 2024 and January 2025. **That is an access failure, not proof the subreddit is quiet.** Do not cite it as absence.
